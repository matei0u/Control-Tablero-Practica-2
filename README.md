# Control-Tablero-Practica-2
Programas desarrollados y librerias necesarias para la resolucion de la practica 2 del PLC de los tableros utilizados en la materia de control digital
El archivo Practica2a.ino contiene el codigo para resolver el reto A, el cual controla la direccion de encendido de luces para la esperial, asi como un stop establecido en un boton.
El archivvo Practica2b.ino contiene el codigo para resolver el reto B, el cual es un semaforo implementado usando maquina de estados.
